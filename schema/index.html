一条机会要有稳定编号

id 用小写字母、数字和连字符。以后更新数据集时编号不变，本机的星标和笔记才能对上。编号消失后，笔记仍留在“已保存”，并标明当前数据集里没有这条。

必须能区分的事实

  • 国家、学科、开放 / 未公布 / 已截止。
  • 国际学生：接受、不接受或未说明。中国申请人：明确包括、只见到国家留学基金委渠道、不包含或未说明。
  • 资助覆盖：全额、部分、带薪职位或未说明。金额带 ISO 货币和单位，程序不换汇。
  • 海外学费差额可以单列。没有单列且两边同币种时，页面只做减法并写明未计杂费。币种不同则不计算。
  • 每个日期有角色：申请开放、可行动的内部期限、最终外部截止，或其他。有时刻就必须给 IANA 时区，不能省略后当成 UTC。只有日期则不换算到上海。
  • 入学时间、资助起止按原文，不当成申请截止。
  • 申请路线按 order 排列，步骤类型包括联系导师、入学申请、校内提名、资助申请、国家留学基金委或其他。
  • 材料分学位、语言、研究计划、写作样本、推荐人。空着表示数据未说明。
  • 学校声誉和学科声誉分开。有序位数字时必须写明数字的含义。没有序位就不参与排序。
  • 至少一条来源网址，以及核验日期或明确的未核验状态。不确定之处用 uncertaintyFlags 和 uncertaintyNotes。

明确不收的字段

不要写录取概率、国籍、绩点或语言成绩。多出来的键会被拒绝，以免一份看起来精确的数字混进卷宗。

私人备份是另一个文件

kind 为 phoebe-phd-private，app 为 phoebe-phd-funding。记录以机会编号为键，内有星标、个人优先级、阶段、笔记和带日期的待办。它不包含资助正文。合并时星标取并集，笔记两边都保留，同一待办以较新的文字为准，但任何一边已完成就保持完成。

资助数据和私人笔记分开存在这台浏览器的 localStorage，键名是 phoebe-phd.public.v1 与 phoebe-phd.private.v1。不跨设备同步，助手也读不到。

星标不会自动开始研究，也不会联系导师或提交申请。按 / 可聚焦搜索。
